# RSNA Knee Abnormality Detection

Learning-first exploration of knee MRI studies for the RSNA Kaggle competition.

## Roadmap

1. Dataset overview: studies, series, labels, and reports.
2. DICOM metadata: geometry, spacing, orientations, and sequences.
3. MRI visualization: load, order, and inspect slices and series.
4. Later: preprocessing, ROI experiments, report analysis, baseline, evaluation, and submission.

## Setup

Create a Python environment and install `requirements.txt`. In Kaggle, add the competition dataset through **Add Input**; keep competition data out of Git. The notebooks are starting outlines and require the competition dataset before execution.

Set the dataset path in each notebook after attaching the Kaggle input. Verify file names and columns against the actual competition data before building the analysis.
